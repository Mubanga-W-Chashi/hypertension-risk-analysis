🩺 Hypertension Risk Analysis & Dashboard

📌 Overview

This project analyzes hypertension risk factors using population health data.
The workflow includes data cleaning, exploratory data analysis (EDA), and interactive dashboard development using Power BI.


⚙️ Tools Used

* Python (Pandas)
* Power BI


📊 Key Insights

* Hypertension prevalence is ~52% in the dataset
* Risk increases significantly with age
* Family history is a major risk factor (~66% vs ~38%)
* Smoking is associated with higher hypertension rates
* BMI shows weak standalone influence
* Exercise shows no clear protective effect; patterns likely reflect confounding factors


📈 Dashboard Features

* Hypertension rate overview
* Risk factor comparison (Smoking, Family History, Exercise)
* Age-based risk segmentation
* Interactive filtering (Age, Smoking Status, Exercise Level)
